# Native protocol probes

[Runner](../../README.md) · [Modules](../../src/native/README.md) · [Harness](harness/README.md) · [Evidence](evidence/README.md) · [Unit tests](../unit/native/README.md) · [Containment](containment/README.md)

These probes run the real pinned binaries (Claude Code `2.1.317`, Codex CLI `0.162.1`) against loopback fixtures to prove protocol behavior. They do not prove subscription auth, and they never use a real login, real home state or the network.

```bash
npm run test:native --workspace=@fluent-flow/runner
```

The script runs `vitest --config vitest.native.config.js` through [`harness/netns-launcher.js`](harness/netns-launcher.js). The launcher uses an unprivileged user, network and mount namespace whose only interface is `lo`, and sets `FF_NATIVE_REQUIRED=1`. The default `vitest.config.js` excludes `tests/native/**`, so `npm test` never spawns a native.

When `COLLAB_CONNECTOR_TEST_DATABASE_URL` is exported (127.0.0.1 with an explicit port), the launcher bridges exactly that database into the namespace ([harness](harness/README.md)); without it there is no bridge.

Rules:

- Every probe file awaits `assertNetworkIsolation()` in `beforeAll`. A run outside the launcher fails with `network_isolation_unavailable`.
- A file may skip only when its binary is absent, `CI` is unset and `FF_NATIVE_REQUIRED` is not `1`. A version mismatch always fails. Binaries come from `FF_NATIVE_CLAUDE_BIN` / `FF_NATIVE_CODEX_BIN` or `PATH`.
- Each file builds an explicit `parentEnv` with `HOME` set to a temp home. The spawn env is `buildNativeEnv(...)` plus XDG roots under that home, proxy variables pointing at the deny proxy, `NO_PROXY=127.0.0.1,localhost` and the dummy model route.
- Fixtures listen on loopback random ports with dummy credentials. Proof of no egress is positive: the namespace check passes, `unexpected` stays empty, model request counts match the script and the deny proxy records nothing.
