# Connector tests

[Runner](../../../README.md) · [Implementation](../../../src/connector/README.md) · [External SDK fixture](helpers/README.md)

The unit suites cover durable journal recovery, local allowlists, stable SDK identities, staged grants, permission translation, timeline normalization, observation byte/count limits, artifact containment, real Git cleanup safety and CLI invocation. `runtime.test.js` composes the real modules around the external SDK fixture. `config.test.js` covers standalone profile validation, capacity and the explicit Paseo opt-in. `optional-paseo.test.js` starts child Node processes without the Paseo SDK and checks that standalone config and `runtime.js` load, and that the connector CLI prints the not-installed and opt-in messages.

Task 7 adds: `catalog.test.js` (v2 entries, revision digest, unavailable readiness, Paseo only when enabled, duplicate daemon ids, `PUBLISHED_CAPABILITIES` against the db package's `REQUIRED_CAPABILITIES` through a test-only import), `executor-routing.test.js` (v1 and v2 Paseo journal records unchanged, native routing by frozen backend, revision drift, `integration_disabled`, `profile_unavailable`, `ambiguous` outcomes, controls after profile withdrawal, additional sessions; the supervisor is a fake client at FF's own IPC boundary), `worktrees.test.js` (real Git: run branch from the base ref, barrier before `git worktree add`, reuse, dirty/foreign/unrecorded conflicts untouched, crash adoption, never-forced archive), `native-events.test.js` (a single >1 MiB multi-byte event and a >1 MiB batch from the real ledger through the actual IPC client into the journal, crash before complete delivery, lost acknowledgement, incomplete chunks; the observation mapping), `runtime-native.test.js` (attach or launch the supervisor, standalone-only composition, v2 Paseo pinning with the SDK enabled, native summaries, journal before acknowledgement) and `observation-batches.test.js` (native fragments, accepted only whole). `real-app.test.js` adds a >1 MiB native observation through the actual HTTP app, reassembled once in Postgres and read back through session history.

Task 8 adds: `native-wrapup.test.js` (real Git with a bare upstream, real `sleep` workers in the process-group test containment, the real supervisor handlers behind the real IPC server and client, the real runtime: unavailable containment, a populated earlier-lifetime leaf, a live idle worker (also when its leaf reads empty), an escaped identity, a process whose cwd is in the worktree, a pending request, an owned stop that stays uncertain, an unreadable same-uid process (C2), an admission already past the dispatch check when archive starts (C3: modelled as the queue of a dropped connector connection, since one connection runs its requests in order), the authorized upstream frozen at launch (fix 1: local backup, another remote or ref and a changed push identity refused at preflight and archive; no remote or two unselected remotes leave the run startable but archive `upstream_unverified`; `remote.pushDefault` selects; a HEAD advanced and pushed between the archive's two samples is what the receipt records, and a tracking ref changed between them refuses), the clean pushed archive with no force and a readable receipt, and a symlink escape on an artifact read with no session named) and `native-summary.test.js` (the native cursor on observations, the exact source reference handed to the supervisor and a deliver that carries only the server prompt, refusals before any worker for a missing, foreign or unparseable cursor and an unbound source, incomplete supervisor history, a cross-backend summary profile, and no Paseo fallback when summaries are disabled). `runtime-native.test.js` now uses a native-domain cursor for its summary case.

`worktrees.test.js` (fix 1) also covers `authorizedUpstream` precedence and refspec mapping against real temp Git, and the final archive check's refusals and returned sample; fix 2 adds distinct push or fetch mappings and several push URLs as no authority (with agreeing and repeated ones collapsing), and a URL or mapping added after the freeze refused at the final check; fix 3 adds byte-exact URL identity (whitespace-distinct URLs distinct, a unique whitespace-bearing URL and a byte-identical repeat one target, exact-byte hashes, newline-bearing values unframeable) and a whitespace-distinct URL added after the freeze refused at the final check. `native-wrapup.test.js` (fix 2) covers the same at launch (run starts, `upstream_unverified`) and a second push URL after the freeze (`upstream_mismatch`) at preflight and archive, including (fix 3) URLs differing only by a trailing space.

`poll-cadence.test.js` drives the loop with a scripted client: immediate empty answers cannot spin, held polls and non-empty batches add no delay, stop is prompt, heartbeats and error backoff keep their own timing, and live observations flush promptly and without overlap while a poll is held.

`native-sdk-contract.test.js` runs the actual public `createPaseoApi` mapping over a daemon I/O driver that parses requests with the pinned native protocol schemas. It checks workspace format, agent UUID/provider/model/placement/labels/MCP configuration, send options, numeric timeline cursors, permission replies, replay and preservation of older journal bindings. This catches wire-shape errors the high-level fixture alone cannot prove.

`real-app.test.js` launches the actual Express app, runs migrations on a dedicated PostgreSQL database, and uses the real HTTP client, runtime, journal, loop, executor and observer. Only the external Paseo SDK and stop boundary are faked. It exercises accepted-response loss and restart, scoped MCP setup, more than one observation batch with an ACK loss, plan/usage/Git projections, native question replies/resolution, selected-session follow-ups, cancellation and revoked accepted grants. It creates isolated fixture records and does not reset the schema. `COLLAB_CONNECTOR_TEST_DATABASE_URL` is required and must name a loopback `ff_connector_*` database (`ff_c` is accepted for the assigned local fixture). Never point it at the DB or server package's reset database.

The native usage case sets the actual public snapshot `lastUsage` fields, observes native idle, and exercises startup/reconciliation and observer restart. It asserts one cumulative sample, raw input/cache/context/cost provenance, zero/null distinctions, updated values and project insights without summing overlapping turn usage.

The privacy case verifies actual app JSON, outgoing observation JSON and the local observation journal omit known fixture paths and credentials in tool, permission and assistant text. Native MCP credentials and permission inputs remain exact. Runtime restart coverage loads private seeded credentials plus newly retained reporting credentials before native backfill. `redaction-context.test.js` checks private modes, atomic replacement, restart, malformed files and symlink refusal; `observation-privacy.test.js` documents the narrow known-value scope.

The archive case uses a disposable local Git repository and bare upstream, queues real HTTP preflight/archive commands, removes only the fixture directory at the external SDK boundary, and delays native confirmation to prove concurrent Git sampling waits. It verifies the exact confirmed HEAD remains historical in delivery review across runtime restart, one stable archived observation is stored, and another workspace missing without a receipt remains unknown. Journal tests cover pre-existing successful wrapup receipts and reject failed, session-only, dirty or foreign cleanup as archival authority.

```bash
COLLAB_CONNECTOR_TEST_DATABASE_URL=postgres://ffuser@127.0.0.1:55432/ff_connector_test npm test --workspace=@fluent-flow/runner
npm run typecheck --workspace=@fluent-flow/runner
```

These tests do not execute a paid model. Real daemon/model and browser UAT remains a separate controlled acceptance gate.
