# Supervisor unit tests

[Runner](../../../README.md) · [Modules](../../../src/supervisor/README.md) · [Containment tests](../../native/containment/README.md) · [Helpers](helpers/README.md)

These run in the default `npm test` and never spawn a native binary. Each test uses its own temp directory. Process cleanup signals only fixture-owned processes whose recorded identity (pid, start time, boot id) still matches.

| File | Covers |
| --- | --- |
| `ledger.test.js` | Same digest returns the recorded state, another digest is rejected, reopen classification per effect, no repeated `create_native_session` barrier, worker intent without identity, injected ENOSPC on fsync, unknown version, metadata-only `respond` barrier and `open()` effect scoping. |
| `owner-lock.test.js` | Real `flock` processes: a second acquire fails while the first holds; killing only the flock parent keeps the lock held by its command and killing that command frees it; the lock descriptor reaches the flock command but not its default or detached `spawn` children; a second supervisor gets `OwnerLockHeld`, the supervisor refuses to start without the lock, and `/proc/<pid>/cmdline` hides the instance id and state path. A symlinked or 0644 `supervisor.log` or `owner.lock` is refused before launch, with the target unchanged. A launch creates both 0600, and `verifyOwnerLock` is false for a symlinked `owner.lock`. |
| `ipc.test.js` | Socket path and directory privacy (including the XDG fallback), symlinked, foreign-owned or wider-mode directories, a server without the secret, a client without the secret or with another instance id, one connector at a time, and that captured socket bytes never contain the secret. |
| `ipc-bounds.test.js` | Real sockets: a frame that crosses 1 MiB only with its final chunk is refused before parsing, exactly 1 MiB (with a multibyte character split across chunks) is admitted and one byte more is not, an oversized reply becomes `response_too_large`, a burst behind a blocked handler gets `overloaded` beyond 64 requests, a reader that stops reading is dropped, a legal-size request with a huge id while the queue is full drops only its own connection (the server keeps serving), and invalid ids or envelopes reach no handler and get no reply. |
| `stop-authority.test.js` | Fake cgroup files only, no real kill or signal. `stop` never writes another instance's scope, a mismatched generation, a stale-boot leaf or a symlinked alias. It kills an exact owned leaf with a current identity or with an intent only. Unavailable containment and a missing leaf with a live identity are `uncertain` with `populated: null`. A dead identity's missing leaf and a verified empty leaf are still `stopped`. A descendant vanishing mid-walk does not hide a populated root. |
| `private-files.test.js` | A symlinked ledger (including to a 0600 file), a wider mode, a directory or a foreign owner fail with `supervisor_file_unsafe`, leaving bytes and mode unchanged. A new ledger is 0600. An unknown version followed by a torn tail keeps the exact bytes, and a valid torn tail is still repaired. |
| `backend-contract.test.js` | Per-call barriers: two commands on one worker never share one, single use (also after a failure, with nothing written), only prompt/respond/interrupt, refs cannot restate identity, typed respond metadata, and question-mcp `answer_barrier` records mapped onto the same respond barrier. |
| `spool.test.js` | 10,000 events read by a consumer that detaches with unacknowledged reads, then reconnects; and PID reuse detection by start time and boot id. |
| `native-dispatch.test.js` | Task 7, over the real ledger, real Git worktrees and contract-faithful fake backends with in-memory containment operations (no process signalled, no cgroup touched): effect order and binding before acceptance, refusals before any effect (revision, readiness, containment), deliver and follow-up barriers with replay, suppressed prompts and withdrawn answers recorded as `no_write` (never a receipt), controls to the recorded worker after the profile is withdrawn, the once-only exact-leaf owned stop (`quiesced`/`uncertain`), a profile violation spooled with its quiesced stop, question answers and registered local values removed before the first spool write, earlier-lifetime work blocking new admission, a worktree conflict untouched, an uncertain create reconciling without reopening, and an additional session in the run worktree. |
| `summary.test.js` | Task 8, over the real ledger: `summarySourceText` returns the session's assistant text through the frozen cursor inclusive and nothing later or from another session, reads Codex agent messages and keeps one oversized event whole, and refuses a null or non-integer cursor, a foreign or other-backend domain, a cursor beyond the history or on another session's event, an unknown session, another run and a prefix without assistant text. |
| `slots.test.js` | `holdsSlot` and `createSlots` over the real ledger, and the supervisor's `reserveSlots`/`releaseSlots`/admission with real Git worktrees and in-memory leaves listing their pids. An active turn, a pending request, an unclassified descendant in the leaf, an escaped worker and unreadable activity keep the slot; an idle worker whose leaf holds only its own pid or backend-verified retained infrastructure frees it without being closed or killed, while any additional or unreadable descendant still holds it; the next launch is admitted while the worker lives; primary and summary share the pool (a summary is deferred with no effect); a lowered cap stops admission and keeps existing reservations; reservations survive a restart and unknown earlier-lifetime activity holds until its leaf is proven empty. Concern passes: grant batches survive a disconnect and are reported held with their deadline; a `slotHeld` redelivery uses a held grant at zero capacity and a lost-ACK replay takes nothing; over the real IPC server and client, a granted submit still running when its connection drops uses its own grant once and the reconnected connector finds nothing of it to return; a release only touches its own batch. |
| `summary-compose.test.js` | Task 8 C1: real ledger, real Git worktree, fake backend. A frozen source larger than one 1 MiB IPC frame (and than 200,000 characters) reaches the summary worker's single prompt whole, in order, with its source correlation and without later text, under one prompt barrier; a missing source, another backend's domain, a cursor beyond the history and an unknown source refuse with `summary_unavailable` before any summary worker opens. |
| `worktree-users.test.js` | Task 8 C2: the /proc worktree-use scan over an injected filesystem: cwd and fd hits, the supervisor excluded, permission-denied cwd, fd directory, single fd or ownership counted as unverifiable, a gone process skipped (also when it vanished during a denied read), a closed fd skipped, another uid excluded after its owner is read. |
| `local-answer.test.js` | Task 9, over the real ledger, the real spool privacy pass and the real `ff_questions` server with a codex-shaped worker: no answer bytes and no sha1/sha256/md5 (hex or base64) of them in any file under `stateDir`, the echo spooled as `[local answer]`, the tool result withheld, `resolvedBy: 'host'` with no value, the metadata-only ledger records; a repeated `localCommandId` never redispatches (also after a restart, and an id accepted before its barrier never dispatches); concurrent web and local answers produce one native response and never overlap at the worker; another generation is refused; `answer_on_host` and `invalid_response` come back unchanged; a native disconnect answers nothing; fix 1: a replayed local id with a barrier but no receipt, or a receipt but no outcome, stays reconciling over the real reopened ledger with no outcome appended and no dispatch; a later ordinary question offering earlier local values is answered from the web by option id (unknown, repeated, cross-question, mixed and stale-fingerprint ids refused before any barrier) and nothing spooled after registration holds those values. CLI: non-TTY refused before any connection, the warning before raw-mode input, masked entry, option numbers and other text, an unknown request refused without input; both actual entry points refuse a non-TTY before any startup. |
| `stop.test.js` | Task 11, injected containment only: `stopContained` is `quiesced` only after a `populated: false` read, kills the exact leaf only after the grace period, is `uncertain` when still populated after `killWaitMs` or when `populated` is unknown, and without a verified leader skips SIGTERM and kills the leaf at once. |
| `recovery.test.js` | Task 11. `recoverOnStart` over the real ledger with fake cgroup files and real sleeping processes recorded as old workers: a populated leaf is quiesced before the command is marked `reconciling`; an unverifiable leaf, a reused PID with other start ticks and a boot-id change are never signalled; ENOSPC stops admission and preserves the ledger; exact no-write evidence resolves only its own barrier; a worker that ended on its own mid-turn leaves its session reconciling; nothing is respawned or replayed. `detectEscapes` reports a live observed process outside the scope and nothing for a gone, reused or other-boot identity. Supervisor lifecycle over the dispatch fakes: worker death expires its generation's requests and reconciles after its owned stop; an explicit prompt resumes the exact session without replay; an operator Cancel closes a bound but unadmitted session only after its old worker is quiesced, releases its slot and the admission gate, and stays closed on replay and restart; an unprovable stop closes nothing; `stop` interrupts active turns with receipts and keeps worktrees; an escaped descendant blocks wrap-up and shows in `status`. |
| `cli.test.js` | Task 11, over the real IPC server and client: `status` and `list` print no prompt, output, credential, native id or path; a stopped supervisor shows `Supervisor: not running` and nothing starts; `stop` reaches only its own instance; an unconfirmed stop prints the shutdown message and exits 1; an unknown command is refused. |
| `containment.test.js` | Decision logic only, on a fake cgroupfs and procfs under a temp root. An injected `fs` adds the kernel's interface files on `mkdir`. Real descendant containment is proven only by the [containment suite](../../native/containment/README.md). |

The owner-lock tests launch the real supervisor entry. It probes the real host cgroup, and on a host with delegation it creates and then removes its own `ff-<hash>` scope.
